description: Harness alias for reviewing recent changes for scope, correctness, and safety.
---

Instructions:
- Run the Review phase only.
- Review changed files only.
- Check against acceptance criteria.
- Check for scope creep.
- Check trading safety boundaries.
- Check that no secrets, local DB files, generated data, or cache files were added.
- Check whether GitNexus analysis should be re-run.
- Output:
  - pass/fail
  - issues found
  - required fixes
  - optional improvements
